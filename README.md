A one-line entry for the make.fun competition "Funniest Sign on a
Haunted Server Room Door": the funniest sign for the door of a haunted
server room.

## The entry (103 characters)

> Do not enter. The servers whisper your passwords, the lights flicker in binary, and IT never came back.

103 characters, one line, inside the gate of 1–120 characters. The
sign opens with the classic "Do not enter", then the haunting turns
specific to a server room — the servers whisper your passwords, the
lights flicker in binary — and the punch lands on the last four
words: IT never came back, so whoever went in to fix it is part of
the haunting now.

## How to run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `entry.txt` into the output directory, containing exactly
the line above, with no trailing newline.
